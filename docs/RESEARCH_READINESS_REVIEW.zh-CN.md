# RoleWeaver 研究就绪性审阅

核查日期：2026-10-16。审阅基线：`3ac7d81`。本次覆盖会话隔离、记忆持久化、上下文预算、角色设定边界、评估记录与部署默认值。

RoleWeaver 当前适合称为长期角色对话的实验原型。代码实现、离线规则回归和真实模型效果是三种不同证据；现有 smoke 分数不能证明人格稳定性改善，也不是独立论文实验的复现。

## 本次修复

- 会话名不再允许点路径、Windows保留名或有损清洗后相互覆盖；过长配置目录保留哈希。
- 记忆、图谱和摘要ID不随删除/淘汰重新编号；持久化下一ID，防止重启后把旧引用分配给新记录。
- JSON先序列化再同盘原子替换。损坏的记忆JSON显式报错，不当作空库继续覆盖。该修改不提供多进程事务或并发写锁。
- 上下文预算按真实窗口及生成预留量检查，移除小窗口仍放行512 token的下限。
- 对话提炼结果不能把角色canon写入伪装成skill来源，也不能覆盖受保护角色主体；记录拒绝计数。
- 角色名、用户称谓、system prompt与角色种子参与记忆范围指纹。快照保存实际展开后的skill，并在恢复时避免重复拼接或读取后来修改的文本。
- API对重名会话跨范围歧义和旧范围迁移返回冲突信息；静态资源目录使用路径包含关系，阻止同前缀兄弟目录越界读取。
- A800启动脚本默认绑定127.0.0.1，并给出SSH访问说明。管理API仍无应用层鉴权。
- memory smoke移除答案提示、固定时钟与同秒recency排序，报告保存查询与源码哈希。
- drift保存全部轮次；filler不计入评分分母。记录规则、配置/kernel哈希和运行元数据；空回答明确失败。
- 清理固定角色专属桥接、配置、前端和资源依赖；保留通用学习、角色SFT工具、Qwen3训练及Live2D/VTube Studio接口。训练数据需显式指定，头像路径通过环境变量配置。

## 验证方法

建议Python 3.12，创建独立虚拟环境后运行：

```powershell
python -m pip install -r requirements-test.txt
$env:PYTHONUTF8 = "1"
$env:HF_HUB_OFFLINE = "1"
$env:TRANSFORMERS_OFFLINE = "1"
$env:ROLEWEAVER_BACKGROUND_WORKER = "0"
python -m unittest discover -s tests -v
python eval/memory_benchmark/run_memory_os_benchmark.py
```

`requirements-test.txt`固定本次使用的直接测试依赖；它不是GPU训练环境锁文件。本次134项离线测试全部通过，无跳过；测试不需要torch、模型权重或在线生成API。前端JavaScript语法、Vue模板编译及14个视图渲染检查通过。QQbot和LINEbot文件相对审阅基线无改动，未连接真实Bot服务。

新版memory smoke为8/8，标准包括top-5召回和状态检查。例如当前饮品目标位于第2位，也会通过。不能解释为100%回答准确率、优于lexical基线或真实模型长对话效果；v1与v2查询已变，分数不宜直接比较。

## 升级及数据兼容

本分支改变记忆范围指纹和部分会话名。旧文件保留；检测到旧范围的同名会话时会要求显式迁移，API返回409，不会静默开启空会话。已有错误编号的历史引用不会被自动推断修复。

迁移前停止所有服务，备份整个memory_root到扫描目录外。核对错误提示中的旧/新路径及角色身份后，再把对应完整会话复制到新范围，更新`short_term/session_meta.json`中的`memory_scope_path`以及其中和旁边`settings_snapshot.json`的实际配置快照。不要把不同角色的旧范围自动合并；应先审查旧数据是否混杂。完成后将旧会话移出扫描目录，避免同ID在两个范围同时出现。若不需要旧会话，保留备份并建立新会话即可。

备份必须包含新增的`memories*.json.meta.json`高水位文件，连同摘要状态和图谱一并保存，不能只复制记忆列表。回退到旧代码后继续删除/写入，可能再次破坏稳定ID保证。
