# RoleWeaver Update - 2026-04-28

This update moves RoleWeaver from a role-chat prototype toward a memory-aware role runtime.

## Highlights

- Added a project-local `runtime/` setup flow and updated launchers to prefer it.
- Added a ChatGPT-like Web UI with multilingual settings, session restore, memory management, and training controls.
- Added LINE bot support with webhook handling, text/image messages, optional voice replies, wake-up push, and daytime text-first policy.
- Added `model_loader_mode`, so text LoRA adapters trained with `AutoModelForCausalLM` can be loaded separately from vision models.
- Added M4.2-M4.6 Memory OS work:
  - editable memory records with reason/evidence;
  - contradiction links and automatic contradiction detection;
  - reflective memory maintenance;
  - forgetting and validity decay;
  - explicit memory layers: short-term, mid-term, long-term, graph, contradiction graph, and reflection notes.
- Added M5.1-M5.2 persona regression:
  - local/API persona regression harness;
  - rule-based persona kernel scoring for identity, autonomy, memory-boundary pollution, and media adaptation.
- Added structured docs for `persona_kernel.json`, memory item schema, technical architecture, and product direction.

## Why It Matters

RoleWeaver now treats character autonomy as a first-class runtime constraint. Memory can personalize the relationship, but it should not rewrite the character. This update gives the project the data structures, tests, and diagnostics needed to keep that boundary visible.

## New Useful Commands

```powershell
setup_runtime.bat
start_roleweaver.bat
line\start_line_bot.bat
runtime\Scripts\python.exe eval\persona_regression\run_persona_eval.py --dry-run
runtime\Scripts\python.exe eval\persona_regression\run_persona_eval.py --local --config-file roleweaver.config.csv --score-persona-kernel
```
